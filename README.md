# Taller 1 - Sistema de Control del Grupo POO
*Este proyecto es un codigo de Java que se desarrolla para gestionar el ingreso al grupo de la asignatura de POO, filtrando alumnos inscritos formalmente de aquellos que no pertenecen al curso o intentan ingresar mediante enlaces públicos.

# Aclaraciones tecnicas
*No se uso nada de POO
*Solo se usaron vectores estáticos
*Se usaron las siguientes librerías `Scanner, File, FileWriter, BufferedWriter, IOException`

# Requisitos
*Lenguaje: Java
*IDE recomendado: Eclipse
